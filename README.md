
# Festinhas Criativa Papelaria — Next.js 14 + Tailwind

## Rodar local
```bash
npm install
npm run dev
```
Abre http://localhost:3000

## Deploy na Vercel
- Faça push para GitHub (repo novo)
- Em vercel.com → Add New Project → Import Git Repository
- Vercel detecta Next.js automaticamente → Deploy
